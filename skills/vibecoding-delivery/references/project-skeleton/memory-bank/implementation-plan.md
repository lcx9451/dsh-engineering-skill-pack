### Step 1：项目脚手架与检查链

| 项 | 内容 |
|---|---|
| **输入** | `docs/tech-stack.md`、`docs/CONSTRAINTS.md` |
| **动作** | 初始化仓库与 `package.json`；配置 tsc strict、eslint、prettier、vitest；写入 `check:fast/task/full` 脚本；接入 CI 骨架 |
| **产出** | `package.json`、`tsconfig.json`、`eslint.config.js`、`.github/workflows/ci.yml` |
| **测试** | 一个"必过"的冒烟测试，证明测试框架可用 |
| **验证方式** | `pnpm check:task` 全绿 |
| **退出标准** | 上述命令通过；且有**一条故意制造的失败**被拦住过（Gate 3 演练） |
| **回滚** | 删除本步文件，仓库回到空状态 |
| **规模** | <200 行 |
| **对应验收** | 无（基础设施） |
